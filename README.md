# Relative-call 親戚稱謂小幫手

忘記親戚怎麼稱呼時,拍一下就能看到「該叫他什麼」。

- 兩個場合分組:🧧 過年、🏮 宗親會(一個人可屬於多個場合),辨識只比對該場合的人
- 📷 即時相機辨識(可多人同時辨識)/ 用照片辨識
- 🖼 照片牆 + 搜尋(辨識失敗時的備援)
- 稱謂、名字、備註/輩分皆手動填寫
- 資料只存在手機瀏覽器(IndexedDB),不上傳;可備份匯出/匯入 JSON
- 純靜態網頁(PWA),人臉辨識用 face-api.js 在瀏覽器內執行,模型已內建可離線使用

## 執行
```
python3 -m http.server 8000
```
手機相機需要 https(或 localhost)。可部署到 GitHub Pages 後,用手機開啟並「加入主畫面」。

## 調整準確度
`app.js` 的 `MATCH_THRESHOLD`(預設 0.5):越小越嚴格、越不容易認錯,但也更容易「認不出來」。每人建議 3~5 張不同角度的照片。
